# 采购审批管理系统 - 自测报告

## 硬性门槛说明

本系统通过Docker Compose实现一键启动，执行docker compose up命令后即可完成全部服务的部署与运行。数据库采用PostgreSQL容器化部署，后端API服务监听5001端口对外提供RESTful接口，前端Web应用通过Nginx代理运行在3000端口。启动完成后，系统自动执行数据库迁移并初始化测试数据，用户可直接通过浏览器访问http://localhost:3000进入系统主界面。三个容器均正常运行，健康检查通过，符合Docker Delivery Standard要求。

## 交付完整性说明

系统完整实现了需求规格文档中定义的全部功能模块。用户管理模块支持五种角色的登录与权限控制，采购申请模块实现了申请的创建、编辑、提交、撤回等全生命周期管理。审批工作流基于WorkflowCore框架构建，支持金额分级的三级审批流程，审批操作包含同意、拒绝、退回三种类型。通知中心实现了系统内消息的推送与已读标记功能，仪表盘页面集成了Ant Design Charts图表库展示申请状态分布与采购趋势数据。数据库预置了五个测试用户和三个示例采购申请，便于功能验证。

## 工程与架构质量说明

后端采用ASP.NET Core 8框架，遵循清晰的分层架构设计，包括Controllers层处理HTTP请求、Services层封装业务逻辑、Models层定义数据实体。工作流引擎使用WorkflowCore实现采购审批流程的编排与状态管理，支持异步事件驱动的审批操作。数据持久化采用Entity Framework Core搭配PostgreSQL数据库，支持自动迁移与种子数据初始化。前端基于React 18与TypeScript构建，使用Vite作为构建工具，状态管理采用轻量级的Zustand库，路由通过React Router实现SPA导航。

## 工程细节与专业度说明

系统实现了完善的错误处理机制，API接口统一返回规范化的JSON响应，包含状态码与错误消息。前端通过Axios拦截器实现请求头自动注入与错误统一处理。数据验证在后端使用Data Annotations进行模型校验，前端表单采用Ant Design Form组件实现即时验证反馈。Docker配置采用多阶段构建优化镜像体积，后端Dockerfile分离SDK构建与运行时镜像，前端先编译再使用Nginx提供静态资源服务。Nginx配置实现了API反向代理与SPA路由回退。

## Prompt需求理解与适配度说明

系统准确理解了用户需求中的核心要点，即基于WorkflowCore框架实现采购审批管理功能。审批流程严格按照需求定义的金额分级规则实现，五千元以下仅需部门经理审批，五千至两万元需经理与财务两级审批，两万元以上需三级审批直至总经理。角色权限设计符合企业实际场景，普通员工只能查看和管理自己的申请，审批人仅能处理属于其审批范围的待办事项。系统界面语言统一使用简体中文，符合国内企业用户使用习惯。

## 美观度说明

前端界面严格遵循设计规范文档的视觉标准，主色调采用科技蓝#1677FF，辅以浅灰色#F0F2F5作为页面背景色，呈现现代化商务风格。布局采用经典的侧边栏加顶栏结构，侧边栏使用深蓝色背景配白色文字形成专业的管理后台视觉效果。卡片组件采用白色背景配合柔和阴影营造层次感，表格设计包含斑马纹与悬浮高亮效果提升可读性。状态标签使用语义化配色，待审批蓝色、已通过绿色、已拒绝红色，信息传达直观清晰。登录页面采用渐变蓝色背景配居中白色卡片，整体风格统一协调。
