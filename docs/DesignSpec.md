# 采购审批管理系统 - 视觉设计规范

## 设计理念

**风格定位**: 现代化商务风管理后台  
**设计原则**: 清晰 · 高效 · 专业 · 信任  
**基础框架**: Ant Design 5 设计体系

## 4. 组件规范 📦

### 4.1 按钮 (Button)

| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | 蓝底白字 `#1677FF` | 主操作：提交、确认、新建 |
| Default | 白底蓝边 | 次要操作：取消、返回 |
| Danger | 红底白字 `#FF4D4F` | 危险操作：删除、拒绝 |
| Text | 无边框蓝字 | 链接式操作 |
| Disabled | 灰色 `#D9D9D9` | 禁用状态 |

**按钮尺寸**:
- Large: 40px 高度 (页面主操作)
- Middle: 32px 高度 (默认)
- Small: 24px 高度 (表格内操作)

### 4.2 卡片 (Card)

```css
.card {
  background: #FFFFFF;
  border-radius: 8px;
  box-shadow: 0 1px 2px 0 rgba(0, 0, 0, 0.03),
              0 1px 6px -1px rgba(0, 0, 0, 0.02),
              0 2px 4px 0 rgba(0, 0, 0, 0.02);
  padding: 24px;
}
```

### 4.3 表格 (Table)

| 元素 | 样式 |
|------|------|
| 表头背景 | `#FAFAFA` |
| 表头文字 | `#595959` 14px 600 |
| 行高 | 54px |
| 斑马纹 | 奇数行 `#FFFFFF`，偶数行 `#FAFAFA` |
| 悬浮行 | `#E6F4FF` |
| 边框 | `#F0F0F0` |

### 4.4 表单 (Form)

| 元素 | 样式 |
|------|------|
| 标签 | `#595959` 14px，右对齐 |
| 输入框高度 | 32px |
| 输入框边框 | `#D9D9D9`，hover `#4096FF`，focus `#1677FF` |
| 必填标记 | `#FF4D4F` 星号 |
| 错误提示 | `#FF4D4F` 12px |

### 4.5 标签 (Tag)

用于审批状态展示：

| 状态 | 样式 |
|------|------|
| 草稿 | `<Tag>草稿</Tag>` 灰色 |
| 待审批 | `<Tag color="processing">待审批</Tag>` 蓝色 |
| 已通过 | `<Tag color="success">已通过</Tag>` 绿色 |
| 已拒绝 | `<Tag color="error">已拒绝</Tag>` 红色 |
| 已退回 | `<Tag color="warning">已退回</Tag>` 橙色 |

### 4.6 消息提示 (Message)

- 成功: 绿色图标 + 文字，3秒自动消失
- 错误: 红色图标 + 文字，5秒自动消失
- 警告: 橙色图标 + 文字
- 信息: 蓝色图标 + 文字

## 7. 交互规范 🖱️

### 7.1 加载状态
- 页面加载: Spin 组件居中显示
- 按钮加载: 按钮内置 loading 态
- 表格加载: 骨架屏或 Spin

### 7.2 空状态
- 使用 Ant Design Empty 组件
- 配合引导操作按钮

### 7.3 确认操作
- 删除、拒绝等危险操作需 Popconfirm 确认
- 重要提交使用 Modal 确认

### 7.4 反馈提示
- 操作成功: `message.success()`
- 操作失败: `message.error()`
- 需确认: `Modal.confirm()`
